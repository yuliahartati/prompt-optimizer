# Prompt Optimizer

An AI-powered Streamlit application that analyzes prompts and automatically rewrites them into clearer, more robust, and production-ready versions.

The app helps improve prompt quality by reducing ambiguity, resolving conflicting instructions, strengthening output formatting, and adding missing constraints while preserving the original intent.

---

## Features

- Prompt quality analysis
- Automatic prompt optimization
- Ambiguity reduction
- Output format improvement
- Role and objective clarification
- Constraint optimization
- Structured prompt generation
- Side-by-side comparison
- Markdown report export
- OpenAI GPT-5 compatible
